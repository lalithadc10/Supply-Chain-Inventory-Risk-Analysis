# Project Assets

This folder contains supporting assets used for documenting and presenting the Supply Chain Inventory & Risk Analysis project.

## Contents

### Dashboard Demonstration

The project includes a video demonstration showing:

- Business problem
- Data preparation
- Analytical approach
- PROVE framework
- Supplier analysis
- Demand risk analysis
- Safety stock model
- Scenario Manager
- Executive dashboard
- Management insights

### Dashboard Image

The final executive dashboard is available in the `Dashboard` folder.

### Project Presentation

The assets in this folder are intended to support portfolio presentation, LinkedIn demonstrations and project documentation.
